# 画像・複数音声の編集を有効にする

## 必要なFirebase側の操作

1. Firebaseコンソールで、既存のプロジェクト `klds-voice-zukan` を開きます。
2. **Firestore Database → ルール** を開きます。
3. このフォルダの **firestore.rules 全文** に置き換え、公開します。

アプリのコード変更だけでは、Firebaseコンソール上のルールは更新されません。
追加した音声配列・編集の保存確認用記録・アップロード済み参照の検証に対応するため、
この更新が必要です。公開読み取り・公開書き込みのルールにはしないでください。
所有者UIDの隔離と、未使用ファイルの削除時の保護を維持したルールです。

Storageは既存の `kids_voice_zukan` バケットと初期化済みインスタンスを引き続き使います。
新しい音声にも従来と同じ所有者専用パスと20MB未満の制限を使います。
今回の機能追加に伴うStorageルール・CORS・課金設定の変更はありません。

## 使い方

- 一覧の画像を長押し → **へんしゅう**。
- 写真を選び、既存の切り抜き画面で確定します。
- 各音声の **録りなおす／ファイル** で差し替えます。
- **録音して追加／ファイルで追加** で音声を追加します。
- **なおして保存** でまとめて反映します。キャンセルでは反映しません。
- 音声はカードごとに5件まで。1回の保存で変更する写真・音声は合計5ファイルまでです。
  写真と音声5件を変更する場合は、写真の変更を戻して音声を保存し、
  もう一度編集画面を開いて写真を変更します。
- 一覧のタップでは登録した声から1件をランダム再生。詳細・編集画面では各音声を個別に確認できます。
- 音声の追加・差し替えにも冒頭の無音カットを適用します。
- 録音ボタンを押すと固定のガイドボイス「これはなーに？」を再生し、終了イベントから180ms後、マイクの許可も完了していれば録音します。ガイドの失敗・取消時に録音を勝手に開始しません。

### ガイド音声の差し替え

- `public/assets/audio/voice_what_is_this.mp3` を好みの同名MP3で置き換えてください。ブラウザはアプリのベースパスに合わせて `/assets/audio/voice_what_is_this.mp3` を取得します。
- 同梱音声は生成済みの固定ファイルです。利用者の録音をAIへ送ったり、録音開始のたびに生成料金が発生したりすることはありません。
- 任意の再生成は Replit OpenAI integration を設定した開発環境で `node scripts/generate-guide-voice.mjs`（アプリディレクトリ内）を実行します。再生成のみクレジットを使用します。

### 波形の読み込み

- 未保存の録りなおし・手動カット結果は、URLだけでなくBlob本体を保持して編集します。一時URLの破棄が波形データに影響しない構造です。
- 保存済み音声は取得に失敗した場合、Storageパスがあれば同じ所有者のダウンロードURLを一度再取得します。読み込みは取消・タイムアウトに対応し、「再読み込み」も可能です。
- ブラウザ側からStorageのCORSや権限を変更することはできません。通信・CORS・権限のエラーが続く場合はStorageの設定を確認してください。失敗時に元音声を上書き・削除することはありません。
- 録音後は波形を自動表示せず、そのままカードを保存できます。
- 後からカード長押し →「へんしゅう」→「波形でカット」で前後を調整できます。
  範囲を変更したときは「この範囲で確定」を押してから保存します。編集画面で録りなおした場合も波形は自動表示しません。

## 保存と安全性

既存の音声1件だけのカードもそのまま読めます。編集では新しいファイルを別パスへ
アップロードして参照を変更し、カードの作成日時を保持します。
保存に失敗した場合も元の写真・声を自動削除しません。
通信断で保存結果が不明な場合、内容を変えずに同じ編集画面から再保存すると保存済みの編集を検出し、
音声の二重追加を防ぎます。別画面で同じ写真・音声が変更された場合は上書きせず案内します。

差し替え前のファイルも即時削除しません。既存の保護者向け未使用ファイル確認で、
保護期間と参照・保存試行の状態を確認したうえで、個別に削除します。
参照中の写真と同じ保存試行に属する旧音声などは、安全のため保護されたままになる場合があります。
